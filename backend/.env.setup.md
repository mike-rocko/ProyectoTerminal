# Guía Rápida:

## 1. Base de Datos PostgreSQL

### Opción A: Supabase (Recomendado - Gratis)
# 1. Ve a https://supabase.com
# 2. Crea proyecto gratis
# 3. Ve a Settings > Database
# 4. Copia la Connection String (URI)
# 5. Reemplaza [YOUR-PASSWORD] con tu password
# DATABASE_URL=postgresql://postgres:[YOUR-PASSWORD]@db.xxx.supabase.co:5432/postgres

### Opción B: PostgreSQL Local
# 1. Instala PostgreSQL: https://www.postgresql.org/download/
# 2. Crea base de datos: createdb tutor_ia_dev
# DATABASE_URL=postgresql://postgres:tu_password@localhost:5432/tutor_ia_dev


## 2. Google AI (Gemini)
# 1. Ve a https://makersuite.google.com/app/apikey
# 2. Crea API key gratis
# GOOGLE_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX


## 3. Secret Key (JWT)
# Genera uno aleatorio con:
# python -c "import secrets; print(secrets.token_hex(32))"
# SECRET_KEY=tu_secret_key_super_largo_y_aleatorio


## 4. Redis (Opcional por ahora)
# Opción A: Redis local
# REDIS_URL=redis://localhost:6379

# Opción B: Upstash Redis (Gratis)
# 1. Ve a https://upstash.com
# 2. Crea database Redis gratis
# 3. Copia la URL
# REDIS_URL=rediss://default:xxx@xxx.upstash.io:6379
